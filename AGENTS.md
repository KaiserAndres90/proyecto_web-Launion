# AGENTS.md - Reglas Globales para la IA

## Stack Tecnológico
- Frontend: Angular 17 (Standalone Components), Bootstrap 5, Animate.css.
- Backend: Node.js, Express, MongoDB, Mongoose.
- Seguridad: JWT, bcrypt, RBAC.

## Reglas de Negocio
- El sistema tiene un embudo de conversión: formulario público -> guarda en BD -> visible en dashboard admin.
- Rutas protegidas por AuthGuard y RoleGuard.
- El diseño debe usar la paleta: Verde Lima (#8CC63F) y Gris Oscuro (#333333).
